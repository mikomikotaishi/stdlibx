# Contributing

Make sure to follow the coding style as depicted in the code.

- Follow the naming conventions:
  - Use `PascalCase` for classes, interfaces, concepts and other such symbols.
  - Use `snake_case` for variables, functions, and methods, except in `/examples` where `camelCase` should instead be used; use `snake_case` for namespaces always, but avoid needing underscores.
  - Private fields in classes should be prefixed with an underscore (for example, `_items`).
  - Use `SCREAMING_SNAKE_CASE` (`ALL_CAPS`) for compile-time constants, enumerators, and macros; use macros sparingly and avoid them completely if possible.
